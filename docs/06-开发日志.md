### 关键设计决策（面试可讲）

**决策一：路径沙箱用「解析后比较路径段」而不是字符串 `startswith`**

```python
# ❌ 错误做法：str(target).startswith(str(root))
#    /data-evil 会被误判为 /data 的子路径
# ✅ 正确做法：Path.relative_to() 会按路径段比较
def _is_relative_to(child, parent):
    try:
        child.relative_to(parent)
    except ValueError:
        return False
    return True
```

**决策二：给模型的错误必须带 `hint`**

`hint` 不是给人看的日志，而是**给模型的下一步动作建议**。
实测把 `hint` 加上后，模型面对 `file_not_found` 会先调 `list_files`，
而不是换个路径继续瞎试。

**决策三：产物统一落到 `outputs/` 且文件名必须清洗**

模型给的 `filename` 可能含 `../` 或 `/`。经 `safe_filename()` 清洗后
`../../evil.md` → `___evil.md`，再拼到 `outputs/` 下，双重保险。
