# 办公 Agent 候选开源项目清单（第二轮·按梯队）

> 调研时间：2026-09-11　筛选标准：能作为"加功能"的基座，优先 Python / Apache-2.0 / 有办公场景

## 梯队一：底座平台（Python + React，可直接在源码上加功能）

### 1. BISHENG（毕昇）— `dataelement/bisheng` ⭐ 11.9k
| 项 | 内容 |
| --- | --- |
| 栈 | **Python 52.9% + TypeScript 44.1%**（FastAPI + React） |
| 许可证 | **Apache-2.0**（无附加条款，改造最自由） |
| 活跃度 | 活跃（上周有提交，v2.6.0 已发布，3.0.0-beta 进行中） |
| 部署 | Docker，4 核 16G 起（推荐 18 核 48G），自带 ES + Milvus + **OnlyOffice** |

**为什么值得重点看 —— 它的原生功能几乎就是你要的办公场景清单：**
- Linsight 通用 Agent（自带 AGL「Agent 引导语言」框架，可把专家经验嵌进 AI）
- BISHENG Workflow：独立应用编排框架，支持**循环 / 并行 / 批量 / 条件分支**，支持 **human-in-the-loop**（工作流执行中途可人工干预，同类产品做不到）
- 官方列出的企业场景：**会议纪要生成**、**固定版式报告生成**、文档审核、**数据分析**、制度更新比对、多智能体协作、简历筛选、**通话录音分析**、非结构化数据治理、知识挖掘
- 企业级能力：**RBAC、用户组管理、分组流量控制、SSO/LDAP**、监控统计、高可用部署
- **自研高精度文档解析模型**：印刷体 / 手写体 / 生僻字 / 表格 / 版面 / 印章识别，可免费私有化部署
- 集成 **OnlyOffice** → 可直接在线编辑 Word/Excel/PPT

**短板**：社区规模小（11.9k star / 53 贡献者），文档与教程不如 Dify 丰富，踩坑时能搜到的答案少。

### 2. Dify — `langgenius/dify` ⭐ 155.4k
| 项 | 内容 |
| --- | --- |
| 栈 | **Python 46.4% + TypeScript 50.4%**（Flask + React/Next.js） |
| 许可证 | Dify 开源协议（Apache 2.0 + 两条附加条件）⚠️ |
| 活跃度 | 极活跃（1-2 天内有提交，v1.17.1） |

- 能力：可视化工作流画布、RAG 管道、Agent、模型管理（数百 provider / 任意 OpenAI 兼容）、插件市场、LLMOps、BaaS API
- 优势：生态最大（1464 贡献者）、中文文档全、二次开发资料最多、国产模型接入成熟
- 短板：邮件/会议/日程**非原生功能**；协议限制多租户 + 禁止改 `web/` 前端 LOGO

| 项 | 内容 |
| --- | --- |
| 栈 | **Python 68% + TypeScript 22.7%** |
| 许可证 | **MIT**（最宽松） |
| 活跃度 | 极活跃（1.12.1，2 天前） |

## 梯队二：通用 Agent 成品（改造量小，产品形态最接近"办公 Agent"）

### 4. Onyx（原 Danswer）— `onyx-dot-app/onyx` ⭐ 32.0k
| 项 | 内容 |
| --- | --- |
| 栈 | **Python 64.4% + TypeScript 27.2%** |
| 许可证 | **MIT**（社区版 CE）+ 企业版 EE 双授权 |
| 活跃度 | 极活跃（v4.7.1，3 天前，314 个 release） |

- 能力：Agentic RAG、Deep Research（多步研究报告）、自定义 Agent、Web 搜索（自带爬虫 + Firecrawl/Exa）、**Artifacts（生成可下载文档 / 图形）**、Actions & MCP（50+ 连接器）、**代码沙箱执行**（数据分析 / 渲染图表 / 改文件）、语音模式、图像生成
- 企业级：协作共享、**SSO（Google OIDC / SAML）+ SCIM 用户同步、RBAC、用量分析、审计历史、自定义代码钩子（脱敏 / 拦截敏感查询）、白标（Whitelabeling）**
- 优势：MIT 协议 + 企业级能力全 + 部署模式可选（Lite 模式 <1GB 内存即可跑）
- 短板：偏"企业知识搜索 + 助手"，不直接操作 Word/Excel/邮件

| 项 | 内容 |
| --- | --- |
| 栈 | **Python 61.7%** + JS/HTML |
| 许可证 | 需二次确认（仓库标注 Readme License，历史上为 MIT） |

## 结论：三条可选路线

**路线 A｜最稳（社区大、资料多）**
`Dify` 做底座 + 自研 React 办公前台 + 插件补齐邮件/会议/日程
→ 风险最低，但要接受多租户与 LOGO 条款限制。

**路线 B｜最契合（功能几乎天生对口）** ⭐ 推荐
`BISHENG` 做底座 + 直接把 8 个办公场景做成工作流
→ Apache-2.0 无约束、Python+React 与需求一致、原生就有会议纪要/报告生成/文档审核/数据分析/RBAC/SSO、自带 OnlyOffice 可编辑 Office、自带高精度 OCR。
→ 代价：社区小、文档少，遇到问题要自己啃源码。

**路线 C｜最快出产品形态（先有个"能干活"的东西）**
`Agent Zero` 或 `Onyx` 做 Agent 内核，外面套自己的多用户 Web 层
→ 立刻能看到产出物（文档/表格/PPT/研究报告），但要自己补权限体系。
